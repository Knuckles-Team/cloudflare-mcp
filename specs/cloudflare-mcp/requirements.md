# CONN-CLOUDFLARE-MCP — Requirements

Governing spec: [spec.md](spec.md).

| ID | Requirement | Acceptance |
|---|---|---|
| `CONN-CLOUDFLARE-MCP-R001` | **Declare the provider upstream.** One `UpstreamDecl` declares the provider MCP server with `kind` `http`, a URL setting, a credential reference and a TLS profile setting. The repository must ship no host name. Caller chain: `connector` → SDK `build_server` → upstream registry. Shape: `cloudflare_mcp/upstreams.py`, SDK `UpstreamDecl`. | `tests/test_upstreams.py::test_upstream_declared_without_host` |
| `CONN-CLOUDFLARE-MCP-R002` | **Probe the upstream tool list.** The `cloudflare-mcp-probe` script must list the upstream tools, count typed schemas and print the SDK fingerprint. It must exit non-zero when the fingerprint differs from `CLOUDFLARE_UPSTREAM_FINGERPRINT`. Caller chain: `cloudflare-mcp-probe` → `probe.main`. Shape: `cloudflare_mcp/probe.py`, SDK `fingerprint_tools`. | `tests/test_probe.py::test_probe_reports_drift` |
| `CONN-CLOUDFLARE-MCP-R003` | **Zone tools.** The connector must serve typed tools to list zones, read one zone and read zone settings. Each is a read. Caller chain: `tools/call` → `GovernanceMiddleware.on_call_tool` → SDK upstream registry → provider MCP server. Shape: provider typed tools served as `cloudflare_<tool>`. | `tests/test_zone_tools.py::test_zone_reads_are_typed_reads` |
| `CONN-CLOUDFLARE-MCP-R004` | **DNS record tools.** The connector must serve one typed tool per operation to list, get, create, update and delete records of kind A, AAAA, CNAME, TXT and MX. Create, update and delete are writes. Caller chain: `tools/call` → `GovernanceMiddleware.on_call_tool` → SDK upstream registry → provider MCP server. Shape: provider typed tools, `governance.is_write`. | `tests/test_dns_record_tools.py::test_one_tool_per_record_operation` |
| `CONN-CLOUDFLARE-MCP-R005` | **Proxy flag.** Record create and update tools must take a typed `proxied` boolean. A record type that cannot be proxied must return a typed refusal. Caller chain: `tools/call` → `GovernanceMiddleware.on_call_tool` → SDK upstream registry → provider MCP server. Shape: `cloudflare_mcp/governance.py` refusal codes. | `tests/test_dns_record_tools.py::test_proxied_flag_and_unproxiable_refusal` |
| `CONN-CLOUDFLARE-MCP-R006` | **TLS mode.** Typed tools must read and set the zone TLS mode. The set tool must accept only `off`, `flexible`, `full` and `strict`. Another value must return a typed refusal. Caller chain: `tools/call` → `GovernanceMiddleware.on_call_tool` → SDK upstream registry → provider MCP server. Shape: `cloudflare_mcp/governance.py` refusal codes. | `tests/test_tls_tools.py::test_tls_mode_closed_set` |
| `CONN-CLOUDFLARE-MCP-R007` | **Email Routing.** Typed tools must enable and disable routing for a zone and manage routing rules and destination addresses. Caller chain: `tools/call` → `GovernanceMiddleware.on_call_tool` → SDK upstream registry → provider MCP server. Shape: provider typed tools served as `cloudflare_<tool>`. | `tests/test_email_routing_tools.py::test_routing_enable_rules_destinations` |
| `CONN-CLOUDFLARE-MCP-R008` | **Mail authentication records.** A typed tool must return the provider-generated DKIM, SPF and DMARC records for a zone. A second tool must publish missing ones. A read-back tool must report `pass`, `missing` or `mismatch` for each record. Caller chain: `tools/call` → `GovernanceMiddleware.on_call_tool` → SDK upstream registry → provider MCP server. Shape: new facade module `cloudflare_mcp/mail_auth.py` over the upstream tools. | `tests/test_mail_auth_tools.py::test_dkim_spf_dmarc_publish_and_verify` |
| `CONN-CLOUDFLARE-MCP-R009` | **Write approval for DNS changes.** Every write tool must apply the SDK destructive-write confirmation. A write without approval must return a typed refusal and send nothing upstream. Caller chain: `tools/call` → `GovernanceMiddleware.on_call_tool` → SDK `ctx_confirm_destructive`. Shape: `cloudflare_mcp/governance.py`. | `tests/test_governance.py::test_unapproved_write_sends_nothing_upstream` |
| `CONN-CLOUDFLARE-MCP-R010` | **Typed refusals.** An unset credential, a rate limit and an upstream error must each return a typed code, not a raw exception. Caller chain: `tools/call` → `GovernanceMiddleware.on_call_tool`. Shape: `cloudflare_mcp/governance.py` `REFUSAL_CODES`. | `tests/test_governance.py::test_each_failure_has_a_typed_code` |
| `CONN-CLOUDFLARE-MCP-R011` | **Zone allow list.** `CLOUDFLARE_ALLOWED_SCOPES` lists the zones the connector may touch. A call that names another `zone_id` must be refused before any upstream request. Caller chain: `tools/call` → `GovernanceMiddleware.on_call_tool`. Shape: `cloudflare_mcp/governance.py` `SCOPE_ARGUMENTS`. | `tests/test_governance.py::test_foreign_scope_refused_before_upstream` |
| `CONN-CLOUDFLARE-MCP-R012` | **Audit.** Every write must record the tool, the arguments, the caller and the approval. The record must hold no credential. Caller chain: `tools/call` → `GovernanceMiddleware.on_call_tool` → audit logger. Shape: `cloudflare_mcp/governance.py` `_redacted`. | `tests/test_governance.py::test_audit_record_redacts_secrets` |
| `CONN-CLOUDFLARE-MCP-R012.1` | **Audit old and new values.** The audit record of a DNS write must also hold the zone, record name, type, old value and new value. Caller chain: `tools/call` → `GovernanceMiddleware.on_call_tool` → audit logger. Shape: `cloudflare_mcp/governance.py`, a read-before-write of the record. | `tests/test_audit.py::test_write_audit_record_has_old_and_new_value` |
| `CONN-CLOUDFLARE-MCP-R013` | **Fleet onboarding.** One fleet entry, lazy namespaces and a passing coverage gate under arbora. Caller chain: arbora fleet catalog → `cloudflare-mcp` endpoint. Shape: workspace manifest connectors group, arbora coverage gate. | `tests/integration/test_fleet_coverage.py::test_single_entry_passes_coverage_gate` |
| `CONN-CLOUDFLARE-MCP-R014` | **Hot-path proof.** Against a fixture upstream, a client must create a proxied record, set TLS mode, enable Email Routing and verify mail authentication over the served connector. Caller chain: `tools/call` → `GovernanceMiddleware.on_call_tool` → SDK upstream registry → provider MCP server. Shape: fixture upstream, `fastmcp.Client`. | `tests/integration/test_edge_journey_served.py::test_record_tls_and_mail_auth_journey` |
| `CONN-CLOUDFLARE-MCP-R015` | **Served coverage.** The connector must serve at least as many tools as the upstream lists, each with a typed input schema. Caller chain: `tools/list` → SDK upstream gate → provider MCP server. Shape: `cloudflare_mcp/upstreams.py`. | `tests/test_coverage.py::test_served_tools_cover_upstream_with_typed_schemas` |
| `CONN-CLOUDFLARE-MCP-R016` | **Declared upstream surface.** `cloudflare_mcp/connector_contracts.py` declares the tools the provider's MCP server publishes as `UPSTREAM_TOOLS` (`search`, `execute`, `docs`, `whoami`, served as `cloudflare_<tool>`), with description, input schema and destructive annotation, and the module states its source. Only `execute` is destructive. The tool-use contracts, links, data location, role, operator prompt and role prompt cover every declared tool, so the connector surface gate passes offline. Depends on: `SCION-CONNECTOR-CONTROL-R916.9`, `PIPE-GATES-R014.12`. | `tests/test_declared_surface.py::test_declared_upstream_tools_match_the_published_list`. |
